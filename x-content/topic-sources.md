# Topic Sources

Where `/x-posts` should look to figure out what's trending **today**, and how to
filter it down to things I can post about credibly. Edit the lists as your
interests shift.

---

## How to find "trending today"

The agent should pull *fresh* signals at run time (not from memory). In order of
preference:

1. **Web search** for the current date — e.g. "AI news today", "Hacker News top
   today", "trending in tech <today's date>", "<my niche> news".
2. **Exa MCP** (`web_search_exa`) if available, for recency-ranked results.
3. **Context7** for library/framework release notes when a post is about a tool.

Always confirm a topic is *actually from the last ~24–48h* before treating it as
trending. If you can't verify recency, label it as "evergreen" instead of
"trending" and pick from the evergreen angles below.

  cloud storage / fun UI (Pluit), desktop AI (Duxy), notes/concept graphs (JotLabs)
- **Motivation / manifesting** — short, genuine, optimistic
- **Internet culture & curiosity** — nostalgia (myspace), digital art, prediction
  markets (Polymarket)

## Accounts & sources worth scanning (signal, not gospel)

- Anthropic / OpenAI / Google DeepMind announcements & model releases
- Cursor + Composer release notes and changelog (I post about these a lot)
- Hacker News front page (news.ycombinator.com)
- Product Hunt daily (producthunt.com)
- Indie hacker / build-in-public conversation on X

> Treat these as inputs. Never quote or attribute claims you didn't verify. I'm
> happy to *speculate or ask* about unreleased stuff — but frame it as a question
> or opinion, never as confirmed news.

## Trend → angle mapping

When something's happening, find *my* angle. My angles are casual and personal,
not analyst-y:

| If the trend is… | My angle is… |
| --- | --- |
| A new AI model / capability | My honest reaction + how it feels to actually use it |
| An Anthropic / Cursor / Composer release or rumor | Excitement, a question, or "here's what I'd switch to and why" |
| Model usage / pricing / limits | A real note from my day ("usage isn't sucking as much up today") |
| X growth / algorithm chatter | My take on the meta-game and what's working on my TL |
| Something in my project's world (color/vision, email, notes) | Tie it to building WhatColor / Ephpha / JotLabs, maybe with a soft plug |

## Recurring evergreen angles (fallback when nothing's trending)

- A short build-in-public update or a small win
- An open question to other builders / an invite to connect
- A friendly reminder that my tools exist and are free to try
- A meta-observation about X or AI culture
- A genuine motivational / manifesting line
- A random curiosity (nostalgia, digital art, prediction markets)

## Do-not-post list

- Mean dunking on people / pile-ons (I keep it positive)
- Politics, culture-war bait
- Stating unverified model rumors as confirmed fact (asking/speculating is fine)
- Corporate or fake-deep "thought leader" voice
- Reposting someone else's insight as my own

> Note: real questions to my audience and honest growth-meta takes are *on-brand*,
> not "engagement farming." The thing to avoid is fake hype and 🧵-bait, not curiosity.
