# Ramble.ai brand source

Drop the official **`MAIN LOGO`** file in this folder (PNG preferred, transparent background).

Once it’s here, the site will use it as:

- `public/logo.png` — mark for hero / sections / footer
- `public/app-icon.png` — squircle app icon for the top-left nav

If you upload `MAIN LOGO.png` (or `.jpg` / `.webp`), tell the agent and it will cut transparency and wire it everywhere.
